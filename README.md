# 雨课堂 AI 助手

雨课堂 Tampermonkey 用户脚本，支持课程播放、动态加密字体读取，以及 OpenAI 兼容接口的 AI 辅助答题。

## 安装

1. 在浏览器中安装 Tampermonkey，并按扩展提示允许用户脚本运行。
2. [安装主脚本](https://raw.githubusercontent.com/652036/yuketang-ai-userscript/master/%E9%9B%A8%E8%AF%BE%E5%A0%82-3.1.0.user.js)。
3. 打开或刷新雨课堂页面，使用“雨课堂刷课助手”面板。

支持匹配 `*.yuketang.cn`、`*.gdufemooc.cn` 和 `examination.xuetangx.com`。网站改版可能影响兼容性。

## AI 答题

在“AI 接口设置”中填写完整的 Chat Completions 地址、模型名称和自己的 API 密钥，例如 `https://api.openai.com/v1/chat/completions`，保存后点击“AI 答题”。

- 支持单选、多选、判断、填空、主观题和投票题的识别与填写。
- 无内置题库或共享 API 密钥；题目和选项会发送到你配置的服务商。
- 密钥默认仅在当前页面会话中使用；勾选“在油猴中记住密钥”后才保存到扩展存储。
- 远程 HTTP 需要单独开启，题目和密钥会以明文传输，优先使用 HTTPS。
- “答题完成后自动提交”可选；有题目失败时不会自动交卷。
- AI 答案可能错误，特别是多选题可能漏选，提交前请检查。

## 课程播放与字体

在课程目录页点击“开始刷课”，可设置倍速、查看进度、暂停或继续。动态字体读取用于提取题目文本，不会把整个页面永久替换成普通字体。不同学校、课件和播放器的支持情况可能不同。

## 验证情况

2026 年 9 月的真实网页测试：

- 加密字体：抽查单选、判断、多选，题干和选项成功还原。
- 30 题测试卷：首次填写成功 29 题；1 题接口连接失败，重试后 30 题均保存，刷新后答案全部保留。
- 本次模型答案对照标准答案为 25/30 题正确，按题目分值折算 31/40；这是特定样本结果，不代表其他模型或题目的准确率。
- 测试通过临时加载脚本和提供 GM 网络接口适配完成；本次未完成 Tampermonkey 安装环境的端到端验证。
- 网页播放器与暂停功能需按实际课件验证；未完成需要 Office/WPS 插件的视频课件测试。

语法检查：`node --check 雨课堂-3.1.0.user.js`。
